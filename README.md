# gaokao-workbench 高考自学工作台

面向在家自学备考高考的单页工作台：今天要处理置顶、学习计划、各科题库（内置基础题 + 自录题）、错题间隔重做（1→2→4→7→15→30→60 天）、知识漏洞清单、每日打卡、测试成绩与得分率趋势、学习统计热力图。

- 单文件 `index.html`，零外部依赖，离线可用
- 选科：物化生（语文 / 数学 / 英语 / 物理 / 化学 / 生物）
- **双仓库架构**：
  - 本仓库（`datafilil/gaokao-workbench`，Public）只放页面代码，开 GitHub Pages
  - 数据单独存于 **私有仓库 `datafilil/gaokao-workbench-data`** 的 `data.json`，外人不可见

**数据存储方式**
- 进入页面后点「GitHub 设置」填入 Token（classic token，勾选 `repo` scope，`ghp_` 开头）
- 填好 Token 后：任何添加/修改/删除操作都会在 2 秒后自动同步到私有仓库 `data.json`
- 父子各在自己设备填一次 Token，之后自动连接，共用同一份实时数据
- 数据安全：Token 仅存于各自浏览器 localStorage；数据仓库为 Private，外人无法访问 data.json

**使用方式**
- 孩子（写数据）：首次打开填 Token → 之后自动同步，无需再填
- 家长（看进度）：同样填一次 Token → 打开「家长看板」Tab 查看统计/预警/漏洞进度

**7 个功能 Tab：**
1. 今天要处理 — 逾期任务标红自动顺延、今日任务、到期错题重做
2. 学习计划 — 物化生按「课本分册 → 章节 → 知识点」三级下拉选任务（融合广东高考考纲 + 人教版教材），登记 / 完成 / 逾期顺延
3. 题库 — 内置 101 道题（语数英物化生基础题 + 广东高考物理真题：2024/2025 卷单选、多选及全部非选择题，含实验与计算题，答案经官方标准答案核对）+ 自录题，看题→显示答案→标记对错，做错自动进错题本
4. 错题重做本 — 间隔复习 1→2→4→7→15→30→60 天，连过 7 轮标记已掌握
5. 知识漏洞清单 — 按学段 + 科目登记，状态流转未学→在学→已掌握
6. 测试记录 — 4 类测试成绩登记 + 得分率趋势折线图（60% 及格线 / 80% 优良线）
7. 家长看板 — 统计概览、预警提醒、近 7 天学习柱状图、今日完成、近期测试、各科漏洞进度

> 提示：高考倒计时自动计算距最近 6 月 7 日的天数。页面公开可访问，但数据需 Token 才能读写，且数据仓库为 Private，外人不可见。

在线访问：`https://datafilil.github.io/gaokao-workbench/`（页面本身可公开打开，数据需 Token 才能读写）。
